How to interpret colors:

  • Variable in golden line, and user line value is valid: var
  • Variable in golden line, but user line value is invalid: varErr
  • Non-variable chars in golden but different in user: differ
  • Non-variable chars in golden line but not in user line: charsInGld
  • Non-variable chars in user line but not in golden line: charsInUsr
  • Non-variable chars in golden and identical in user: sameChars
  • Lines in golden with no similar counterpart in user: (missing line)
  • Lines in user with no similar counterpart in golden: Abc (extra line)
